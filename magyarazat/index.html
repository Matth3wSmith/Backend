PHP Projekt Architektúra

Ismerd meg lépésről lépésre, hogyan épül fel egy komponens-alapú PHP weboldal!

1. Hogyan kapcsolódnak egymáshoz a fájlok?

Az alábbi diagram azt mutatja be, hogy a böngészőből érkező kérések hogyan áramlanak át a rendszeren. Ezt az építészeti mintát Front Controller-nek hívjuk, mert minden forgalom egyetlen központi kapun (az index.php-n) keresztül érkezik.

graph TD User((Böngésző)) -->|Kérés pl. ?menu=3| Index[index.php
Front Controller] Index --> Func[include/functions.php
Segédfüggvények] Index --> Router[include/router.php
Útválasztó] Router -->|menu=1| Fooldal[include/fooldal.php
Tartalom generálás] Router -->|menu=2| Aloldal[include/aloldal.php

Űrlap és Feldolgozás] Urlap -.->|Mentés| Save[(save.txt

HTML Keret] Layout --> Navbar[include/navbar.php
Menü] Layout -.->|Kiíratja a tartalmat| MainContent{{$mainContent változó}}

2. A fájlok részletes magyarázata

Görgess lefelé, hogy megértsd az egyes fájlok szerepét a rendszerben!

index.php - A Központi Irányító

Szerepe: Ez a Front Controller, azaz a belépési pont. Ahelyett, hogy minden oldalhoz külön főfájlt hoznánk létre (pl. kapcsolat.php, rólunk.php), minden kérés ide fut be. Ő a felelős azért, hogy a megfelelő sorrendben "összeszerelje" az oldal darabkáit (függvények betöltése, útvonal eldöntése, majd a kinézet betöltése).

index.php
<?php
    // 1. Lépés: Segédfüggvények betöltése (require_once: kritikus hiba, ha nincs meg)
    require_once("include/functions.php");

    // 2. Lépés: Útválasztó betöltése (eldönti melyik tartalom kell)
    include_once("include/router.php");

    // 3. Lépés: A kinézet betöltése (megjeleníti a router által kigenerált tartalmat)
    include_once("include/layout.php");
?>

include/functions.php - Segédfüggvények

Szerepe: Itt tároljuk azokat a kódokat, amelyeket a projekt több pontján is újra fel akarunk használni. Ilyen a uri() függvény, ami a menü linkek generálásáért felel. A htmlspecialchars használata fontos biztonsági lépés (XSS támadások ellen véd).

include/functions.php
<?php
    //Menüpontok létrehozása
    function uri($menuSzam)
    {       
        // A $_SERVER['PHP_SELF'] megadja az aktuális fájl (index.php) nevét.
        // Ezt fűzzük össze a ?menu=x paraméterrel.
        return htmlspecialchars($_SERVER['PHP_SELF']) . "?menu=" . $menuSzam;
    }
?>

include/router.php - Az Útválasztó (Routing)

Szerepe: Ő a közlekedési rendőr. Megvizsgálja a böngésző címsorát (az URL paramétereket a $_GET szuperglobális tömbön keresztül), és egy switch (többszörös elágazás) segítségével eldönti, melyik aloldalt kell betölteni. A kigenerált HTML szöveget eltárolja a $mainContent nevű változóban.

include/router.php
<?php
    //útvonalVálasztás - A "?? 0" operátor alapértelmezett értéket ad, ha a menu paraméter üres
    switch($_GET["menu"] ?? 0)
    {
        case 1:
        default: // Ha valami mást ír be a felhasználó, automatikusan a főoldal jön be
            include("include/fooldal.php");
            $mainContent = fooldal(); // A függvény visszatérési értékét (HTML) elmentjük
            break;
        case 2:
            include("include/aloldal.php");
            $mainContent = aloldal();
            break;
        case 3:
            include("include/urlap.php");
            $mainContent = urlap();
            feldolgozas(); // Itt hívjuk meg az űrlap feldolgozását is!
            break;
    }
?>

include/layout.php - A Kinézet (View)

Szerepe: Ez a mester-sablon. Egy szoftverfejlesztésben fontos a Separation of Concerns (Felelősségi körök szétválasztása), azaz a logika (PHP) és a kinézet (HTML) minél jobb elkülönítése. Ez a fájl biztosítja a Bootstrap keretrendszert, beemeli a menüt, és a megfelelő helyre "beilleszti" a router által összeállított $mainContent változót.

include/layout.php (rövidített verzió)
<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>Űrlap</title>
        <!-- Bootstrap betöltése -->
    </head>
    <body>
    <div class="container">
        <div class="row">
            <header class="col-12"><h1>Oldal</h1></header>
            
            <!-- Navigáció beemelése -->
            <?php include_once("include/navbar.php");?>

            <div class="col-12">
                <!-- Itt jelenik meg a tényleges aloldal tartalma! -->
                <?php echo $mainContent;?>
            </div>
        </div>
    </div>
    </body>
</html>

include/navbar.php - A Menüsáv

Szerepe: Külön fájlban tároljuk a menüt, hogy könnyen módosítható legyen. Észreveheted, hogy a linkek (href attribútumok) nem konkrét HTML fájlokra mutatnak, hanem a korábban megírt uri() függvényt használják, ami dinamikusan generálja le a ?menu=1, ?menu=2 linkeket.

include/navbar.php (rövidített verzió)
<nav class="navbar navbar-expand-lg bg-body-tertiary">
    <ul class="navbar-nav">
        <li class="nav-item">
            <!-- PHP-val iratjuk ki a biztonságos URL-t -->
            <a class="nav-link" href="<?php echo uri(1) ?>">Főoldal</a>
        </li>
        <li class="nav-item">
            <a class="nav-link" href="<?php echo uri(2) ?>">Aloldal</a>
        </li>
        <li class="nav-item">
            <a class="nav-link" href="<?php echo uri(3) ?>">Űrlap</a>
        </li>
    </ul>
</nav>

include/fooldal.php - Egyszerű Tartalom

Szerepe: Egy egyszerű aloldal, amely egyetlen függvényt (fooldal()) tartalmaz. Ez a függvény szövegként (string) téríti vissza a megjelenítendő HTML kódot. (Szakmai tipp: Modern rendszerekben a HTML-t általában nem írjuk bele stringként a PHP-ba, de tanulási fázisban ez elfogadott megoldás).

include/fooldal.php
<?php
function fooldal(){
    // Egyszerű HTML kód visszatérítése
    return '<img src="include/kep.jpg" alt="" class="img-fluid">
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>';
}
?>

include/urlap.php - Logika és Interakció

Szerepe: Ez a legösszetettebb fájl, hiszen két feladata is van. Az urlap() függvény legenerálja az űrlap kinézetét. A feldolgozas() függvény pedig lefut, ha a felhasználó rákattintott a mentés gombra. Kicseréli a sortöréseket, hozzáfűzi (FILE_APPEND) az adatokat a fájlhoz, végül átirányítja az oldalt. Ezt az átirányítást PRG (Post/Redirect/Get) mintának nevezzük, ami megakadályozza, hogy F5 (Frissítés) gomb nyomásakor az űrlap újra elküldésre kerüljön!

include/urlap.php
<?php
function urlap(){
    $szoveg = "";
    // Az űrlap arra az URL-re küldi az adatot POST metódussal, ahol épp vagyunk
    $szoveg .= '<form action="'.uri(3).'" method="post">';
    $szoveg .= '<input class="form-control" type="text" name="nev">';
    $szoveg .= '<button type="submit" name="adatMentes" class="btn btn-primary">Mentés</button>';
    $szoveg .= '</form>';
    return $szoveg;
}

function feldolgozas(){
    // Megvizsgáljuk, hogy történt-e gombnyomás
    if(isset($_POST["adatMentes"])){
        // 1. Sortörések takarítása (egy sorba fogunk menteni!)
        $szoveg = str_replace(["\r\n","\n","\r"], "\\n", $_POST['szoveg']);
        
        // 2. Mentés a fájl végére, pontosvesszővel elválasztva
        file_put_contents('save.txt', $_POST['nev'] .";". $_POST['email'] . ';'. $szoveg  . PHP_EOL, FILE_APPEND);
        
        // 3. PRG minta: átirányítjuk a felhasználót az adatok megérkezése után
        header("location:". uri(3));
        exit(); // Megállítjuk a további kód lefutását
    }
}
?>

save.txt - Az "Adatbázis"

Szerepe: Mivel a projekt még nem használ SQL adatbázist, az adatokat egy egyszerű szöveges fájlban perzisztáljuk (tároljuk el tartósan). A pontosvessző (;) szolgál az oszlopok, az új sor (PHP_EOL) pedig a rekordok elválasztására (hasonlóan a CSV fájlokhoz).
